- 资源加载优先 `ResourceLoader`（导出包内只有导入产物，原始 `.wav` 不随包），无导入缓存时回退 `AudioStreamWAV.load_from_file()`（干净检出/headless 首跑亦可解码）；WAV 导入沿用 Godot 默认 QOA 有损压缩（体积约 1/5，若要无损把 `*.wav.import` 的 `compress/mode` 改 `0` 后重导入）
- headless 默认静默（`skip_headless`）保证机检零音频开销，机检用 `set_enabled_for_test(true)` 强制开启

**卡通像素风 UI 皮肤（post-W20）**
- `config/ui_skin.json` 是皮肤唯一数据源：`enabled` 开关 / `asset_dir` / `nine_patch` 九宫格边距 / `styles` 15 条样式 / `theme` 主题映射 / `font_colors` 字色；改皮肤不必碰代码
- 22 张像素贴图由 `tools/generate_ui_pixel_assets.py` 程序化生成（零依赖手写 PNG：zlib + IHDR/IDAT/IEND，8-bit RGBA），逻辑像素 × `BLOCK=3` 放大保证块感；可整批替换为美术资源（保持文件名即可，配置无需改动）
- **画法（不是「带描边的矩形」）**：① 四层框架——外描边 → 斜面(亮/暗) → 主框色 → 内暗分隔线；② 四角切 2~3 像素成**倒角斜边**；③ 四角内缩处 2×2 **铆钉**（左上亮、右下暗）；④ 填充竖向**渐变**（顶部 2~3 行受光、底部 1~2 行落影）。所有细节都画在 `texture_margin` 以内，中段只有纯色，拉伸/平铺不糊
- **九宫格尺寸**：面板 24 逻辑（72px，边距 21）/ 按钮 16（48px，18）/ chip 12（36px，12）/ slot 16（48px，15）/ 进度条 8（24px，6）。**细节不能落进中段**——chip 因此不放铆钉（12 逻辑放不下边距），slot 用实线内框而非虚线（虚线横穿中段会被拉成长线）
- **图标按资源名逐个手绘 16×16 点阵**（四档色 `o` 描边 / `X` 主色 / `h` 高光 / `d` 暗部）：心（左上加双高光、右下压暗）、币（外圈金环 + 中央潮汐波纹）、星（五角带棱面）、骷髅（眼窝鼻孔镂空 + 下颌牙）、宝箱（木箱 + 金属包边 + 锁扣）、剑（刃面高光 + 金色十字护手 + 握柄）、光标（白箭头 + 深色描边 + 落影）。**当前仅图集/机检引用，HUD 尚未放置图标**
- 开发期对照表：`python tools/generate_ui_pixel_assets.py --sheet=<out.png>` 把 22 个资源按 4 列放大 3× 拼成一张图，用于目视核对（不写入项目资源）
- 资源清单：4 张面板（dark 常规 / accent 事件卡 / death 死因·挣扎 / gold 进化共鸣）、5 态按钮（normal / hover / pressed / disabled / **lit 已点亮**）、chip、slot_frame、4 条进度条（bg / hp / exp / boss）、7 个图标（心 / 币 / 星 / 骷髅 / 宝箱 / 剑 / 光标）
- **状态语义不混同**：灯塔树三态用三张不同贴图（已点亮绿 / 可购买紫 / 未解锁灰，沿用原扁平样式配色语义）；已点亮按钮 `disabled=true`，文字取 `font_disabled_color`，故该态字色也写进 `styles`（`"font_disabled_color": "#B4E8C4"`）由 `PixelSkin.apply_button_state()` 一并套用——只换贴图不换字色会变成「亮贴图 + 灰紫字」，比可购买态更难读
- **进化共鸣保留金色**：原 `evolution_effect_ui` 传金色 `StyleBoxFlat`，皮肤下若统一走 `panel_accent`（青）会与普通事件卡混同，故单独出 `panel_gold` + `UiChrome.gold_panel_style()`
- **「关掉开关 = 回到原样」**：HUD 挣扎横幅原本是就地 `StyleBoxFlat`（0.80 alpha + 亮红边框），与结算页 `death_panel_style()`（0.92 + 粉红）配色不同；皮肤关闭时保留原就地配色，不套结算页样式
- **退出时不留贴图泄漏**：`PixelSkin` 的 `_theme` / `_tex_cache` / `_style_cache` 是静态变量，卸载时机晚于引擎的纹理/RID 清理 —— 不显式释放则每个已加载贴图都会在退出日志报 `Texture ... leaked`（实测 `character_select` 漏 7 个、`world` 漏 1 个）。修法：`PixelSkin.release_cache()` 由 `world` / `character_select` 的 `_exit_tree()` 调用，且 `UiChrome.chip_style()` 的像素分支不再二次缓存（贴图样式统一由 `PixelSkin` 持有），释放后按需自愈重建。修复后开/关皮肤的泄漏计数与基线完全一致
- `PixelSkin`（`scripts/ui/pixel_skin.gd`，静态工具非 autoload）按配置构建 `Theme`（九宫格 `StyleBoxTexture` + 字色），一处挂载全局继承——不必逐个改 21 处 `Button.new()`
- **九宫格要点**：`texture_margin_*` 保护边角，`axis_stretch_horizontal` 面板/按钮走拉伸（`STRETCH_SCALE`）、进度条走平铺（`STRETCH_TILE`，保留像素块感）；边距必须小于贴图半宽，否则中段被挤成负宽、Godot 静默画成纯色块
- **主题挂载位置（关键坑）**：`CanvasLayer` / `Node2D` 会**截断** Theme 继承链，实测父链 `ProgressBar → HUD(Control) → UI(CanvasLayer) → Main(Node2D) → root(Window)`，因此主题不能挂根 `Window`，必须由 `PixelSkin.apply_to(node)` 递归给「父节点不是 Control 的 Control」逐个挂（覆盖子树里另起的 `CanvasLayer` 段）
- 接线点：`world.gd` / `character_select.gd` / `lighthouse_tree.gd` 在 `_ready()` 调 `apply_to(self)`；`ui_chrome.gd` 的面板/芯片改「先试像素皮肤，null 则回退 `StyleBoxFlat`」；`hud.gd` 经验条显式换 `bar_exp`（主题默认 `ProgressBar.fill` 是血条红）
- 关闭开关（`enabled=false`）时全部回退原扁平样式，`PixelSkin.stylebox()` 自身也检查开关（`hud.gd` / `lighthouse_tree.gd` 会直接调它，不能只靠 `UiChrome.pixel_style()` 把关）
- 贴图双路径加载：`ResourceLoader` 优先（导出包只有导入产物）→ `Image.load_from_file()` 兜底（干净检出无 `.godot/imported`）
- 开发期预览场景 `scenes/ui_skin_preview.tscn`：默认出图集总览，`-- --world` 看实机 HUD，`-- --char` 看选角首屏，附 `--shot` 落 PNG（不参与机检）
