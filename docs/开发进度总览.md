## 三、已实现功能清单

**核心循环**
- 昼夜状态机（夜晚 45s / 精英 60s / 天灾 90s / 终局 120s），夜晚结束无条件进昼
- 玩家 WASD 移动（4.2 单位/秒）+ 经验珠自动吸附 + 潮币拾取
- 升级三选一（武器/被动分类、权重保底、免费重铸、4 武器 / 6 被动槽上限）
- 抉择之昼 UI（DayPhaseUI）+ 结算/死因 UI（ResultUI，含「再来一局」重开 + **W17 死亡原因可视化：最后一击来源 + 伤害来源 Top3**）

**战斗（W5–W9）**
- 武器：8 种（鱼叉枪/灯塔圣火/锚链/锚锤/水母孢子/雷暴云/水母炮/信天翁），数据驱动、自动索敌、1~7 级
- 敌人：9 种（5 基础 + 4 进阶：鸦群/潮汐召唤师/渊潮长枪兵/暗礁巨人）
- 词缀：6 种（分裂/传送/荆棘/迅捷/再生/锁链）
- Boss：3 个多阶段（深渊水母后 #10 / 潮汐执政官 #15 / 吞噬之星 #20）+ 精英夜(5) / 天灾夜(10·15·20) / 夹击(15)
- 对象池（敌/弹道/敌弹/粒子/拾取/潮币）+ 空间哈希 + 确定性 RNG + 潮汐刷怪（稀疏→密集→加压）

**成长（W10）**
- 进化系统：8 条进化路径（武器 + 对应钥被动 → 传说），融合占槽正确 + 钥被动槽返还
- 进化道具掉落：Boss 必掉（无视软上限）/ 精英稀有（第5夜保底 1）/ 宝箱事件受软上限截断
- 进化伤害提升、全屏共鸣特效

**经济**
- 商店（每夜洗牌 6 件、折扣 20%、潮币购买、满槽退款）+ 潮币闭环
