## 2. 阶段 A — MVP 收口（建议 2–4 周）

目标：勾选终验人工项，达到「可对外称 MVP Release」。

### 2.1 人工验收（阻断终验）

| ID | 项 | 文档依据 | 验收方式 | 状态 |
|----|----|----------|----------|------|
| A1 | 350 敌同屏稳定 **60fps** | 验收 5.1 / W19 | Profiler 实测（机检仅证明刷满不崩；Bot 见峰值 350） | 待做 |
| A2 | **首局完成率 ≥ 60%** | W20 / GDD §3.4 | ≥10 人真人试玩统计 | 待做 |
| A3 | 连续 3 局无崩溃 | 验收 5.2 | 打到第 8 夜 ×3 | ✅ Bot 10 局（2026-09-07） |
| A4 | 内存泄漏粗测 / ≤512MB | 验收 5.3 / W19 | 连续 3 局无单调涨 | 待做 |
| A5 | 手感：移动 / 跳过焦点 / 灯塔碰撞 / 可玩到 8–10 夜 | 验收 1.x / 3.3 | 人工试玩勾选 | 部分：3.3/1.1.1/1.1.2/1.2.3 已 Bot 勾；手感项待做 |
| A6 | HUD / 商店 / 事件 / 角色·灯塔树 / 死因页视觉排版 | 验收 4.4.9 等 | 试玩确认可读可点 | 待做 |
| A7 | 进化全屏共鸣 + 双语切词体验 | 验收 4.1.4 / W19 | 人工确认 | 待做 |

### 2.2 已知工程债（仍属 MVP 质量）

| ID | 项 | 现状 | 建议 |
|----|----|------|------|
| B1 | **MultiMesh 合批** | SKILL/README 要求；工程内尚无 `MultiMesh` | A1 不达标则优先；达标可降优先级或降标至 250 敌 |
| B2 | **属性软上限对齐 GDD §6.9** | 暴击/范围等与文档有偏差（代码注释已标明） | 数值校准时对齐，或回写文档说明 MVP 口径 |
| B3 | **宝箱奖励表** | `config/pickups.json` 标「占位」 | 按稀有度补完整物品表（潮币/治疗/进化等） |
| B4 | **美术 / 音效** | 程序化占位；无正式资源 | 最小可替换包（敌人/武器/UI/关键 SFX） |
| B5 | **数值校准** | W20 任务表有 DPS/血量微调 | 结合 CombatLog + 真人通关率 |

### 2.3 建议周序

| 周 | 焦点 | 完成标准 |
|----|------|----------|
| R1 | Profiler 压测 350 敌 + 崩溃/内存粗测 | A1/A3/A4 有结论；若不达标启动 B1 |
| R2 | MultiMesh（按需）+ 数值微调 + CombatLog 复盘 | 帧率达标；通关曲线有调参记录 |
| R3 | 外部试玩（首局完成率）+ UI 排版收口 | A2 统计出炉；A6 勾选 |
| R4 | 美术/音效最小包 + 验收清单终勾 + 进度总览更新 | 可宣布 MVP Release |

## 4. 阶段 C — 抢先体验（MVP + 约 3 个月）

对齐 GDD §3.2。

| 批次 | 内容 | 文档要点 |
|------|------|----------|
| C1 内容扩容 | 角色 3→**10**；武器 8→**20**；敌人 9→**30**；事件 7→**12+**；Boss 增至 3–6 | §3.2 / §6.8 |
| C2 成长补齐 | 进化 **#9/#10** + 精炼 III；再 +≥1 条夜风系（四系均 ≥15%） | §6.5 / §6.6 |
| C3 局外 | 灯塔树 **4×10**（现 3×5） | §7.1 |
| C4 模式 | **无尽**、**每日挑战**、种子分享、成就 | §3.2 / §8.5 |
| C5 系统 | **诅咒契约**（失眠/贪潮等） | §8.5 |

验收代理（文档目标）：局均约 20 分钟（P95 ≤ 25）；D1 完成率 ≥ 50%。

## 5. 阶段 D — 正式版方向（约第 9 个月）

对齐 GDD §3.3。

- 第二章「永冻湾」+ 20+ 新敌人（区域系数预留 1.15）
- 可选本地双人合作（难度 ×1.8）
- 武器幻化 / 灯塔外观自定义（纯装饰，不卖数值）

## 6. 明确不做（当前冲刺禁区）

以下**不得**写入 MVP 收口冲刺或误标为「已实现」：

1. 侵蚀等级  
2. 诅咒契约  
3. 无尽模式  
4. 每日挑战  
5. 精炼 III  

（封测 / EA 阶段按第 3–4 节排期。）
