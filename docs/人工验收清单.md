## F. 地图 / 灯塔 / 黑夜视线观感（W22 + W23，`config/map.json` + `config/night.json` vision）

> 试玩重点：打到**第 2 夜天黑后**停留观察灯塔亮圈与光束，再走向远处看是否**由近及远渐变至全黑**，最后贴着散落光源（荧光藻/贝类/夜明珠）走一圈确认照明衔接。
> **注**：W23 起 `map.json arena.enabled=false`（用户要求去掉地图范围限制），F.4/F.5/F.7/F.8 仅在把 `arena.enabled` 改回 `true` 时适用，当前默认不适用。
> **⚠ 2026-10-26 起视野系统总开关关停**（用户反馈「黑夜遮挡视线实际游戏体验影响不大，去掉所有发光，视线限制设定」）：`night.json vision.enabled=false` → 雾罩/灯塔光束/灯室辉光/散落光源/命中闪光**全部不生效，夜间全图可见**。因此 **F.1–F.5、F.8–F.14、F.16–F.25、F.28 当前不适用**（改为验 **F.31**）；把 `vision.enabled` 改回 `true` 即恢复整套系统，这些项随之恢复适用。**F.6 / F.7 / F.15 / F.26 / F.27 / F.29 / F.30 / F.32–F.35 仍适用。**

> 调参入口（无需改代码）：
> - 灯塔亮圈大小/亮度 `night.json vision.lighthouse_glow_units` / `lighthouse_glow_intensity` / `lighthouse_glow_core_ratio`
> - 边缘暗度 `night.json vision.fog_alpha`（0.98 极黑，调低则透光）/ `fog_color`
> - 渐变曲线 `night.json vision.falloff`（linear / smooth / inverse_square）
> - 光束 `map.json lighthouse.beam.*`（长度/半角/转速/颜色）
> - 散落光源 `map.json scattered_lights.*`（chunk_px 区块边长 / lights_per_chunk 每块个数 / chunk_radius 覆盖区块数 / radius_units 照明半径 / intensity 亮度 / min_gap_units 间距 / kinds 三类型权重与颜色 / **halo_scale 光晕半径=素材半边长×该值** / **sprite_scale 素材缩放**）——恒定亮度，无呼吸参数；**照明参数（radius_units/intensity）与外观参数（halo_scale/sprite_scale）相互独立，改外观不会暗中改难度**
> - 地图范围限制 `map.json arena.enabled`（false=无限制，true=恢复圆形边界；参数全部保留）
> - 被动视野成长 `passives.json` 内 `vision_radius_units` 桶（pearl 夜明珠当前 +1.5 单位/级）
> - 成长节奏 `tools/generate_exp_table.py`（BASE / RATIO / LINEAR 三个常数，改完重跑脚本生成 `config/exp_table.json`）；商店 `upgrade.json shop.max_purchases_per_visit` 与 `weapons.json`/`passives.json` `metadata.shop.cost`
