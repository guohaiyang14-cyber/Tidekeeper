## 1. 完成率公式

\[
\text{首局完成率} = \frac{\text{首局通关人数}}{\text{有效首局人数}} \ge 60\%
\]

- **通关**：打到第 20 夜通关（击杀吞噬之星 / 结算 win）。
- **有效首局**：首次认真开局（角色默认守望者、难度默认守夜人）；中途强退可记「无效」并备注。
- 建议样本量 **≥10**。

## 3. CombatLog 工程代理（非真人终勾）

本机跑过局后：

```bash
python tools/stats_combat_logs.py --a2-proxy --latest 30 --completed-only
# 或 JSON：
python tools/stats_combat_logs.py --a2-proxy --latest 30 --completed-only --json
```

关注：

- `winrate`（全样本通关率，含 Bot，**≠** 真人首局完成率）
- `reach≥8` / `≥10` 里程碑
- 死亡夜直方图：单夜死亡占比是否 **>40%**（GDD §11.1）
- `last_hit` Top（荆棘等）
