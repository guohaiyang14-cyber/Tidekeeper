## 1. 游戏概述

### 1.1 一句话概念

你是潮汐之海上最后一座灯塔的守夜人。每当夜幕降临，深海魔物从四面八方涌向灯塔。你需要熬过 20 个夜晚，用有限的时间收集资源、构筑 Build、点亮"永昼信标"，让黎明永远到来。

### 1.2 核心体验

一句话体验：**"每一夜都在变强，每一夜都在被追上，第十五个夜晚开始你才真正理解自己的 Build。"**

游戏采用俯视角 2D 自动战斗（类《吸血鬼传说》），但把一局切成"战斗之夜 + 抉择之昼"的交替结构（类《土豆兄弟》的波次商店），常规夜 **45 秒**、抉择之昼不限时可跳过，一局标准时长 **约 20 分钟（上限 25 分钟）**。

### 1.3 目标平台与开发语言

- 平台：PC（Steam）优先，随后可移植 Switch / 移动端。
- **引擎与语言（已锁定）**：**Godot 4.7.1 + GDScript（静态类型）**。架构为节点系统 + 对象池（不引入第三方 ECS）；详见仓库 `README.md` / `docs/技术选型.md` 与 [§10](#10-技术设计)。
- 视角与渲染：2D 俯视，像素或低多边形手绘风格，暗色调 + 高对比光效（灯塔光晕是视觉锚点）。

### 1.4 参考游戏与差异化

| 参考游戏 | 借鉴点 | 本作差异化 |
|---|---|---|
| 吸血鬼传说 (Vampire Survivors) | 自动战斗、海量敌人、武器进化 | 增加"抉择之昼"：每夜之间有商店、事件、重铸；武器有槽位上限 |
| 土豆兄弟 (Brotato) | 波次结构、槽位限制、商店购买 | 连续 45 秒大波次战斗与精英/Boss 节奏，减少商店割裂感 |
| 哈迪斯 (Hades) | 局外成长与叙事、死亡不挫败 | 失败结算保底、首夜保护、挣扎模式 |
| 杀戮尖塔 (Slay the Spire) | 三选一、卡池权重与保底 | 「武器+被动」组合替代手牌操作 |

**核心差异卖点**：昼夜交替结构 + 节奏尖峰（精英夜 / 天灾夜）+ "最后的灯火"挣扎复活系统；侵蚀等级为封测调优手段，不作为 MVP 卖点。

## 2. 设计支柱

### 支柱一：成长有锚点

- 所有成长都有明确上限和槽位约束：武器 4 槽、被动 6 槽、属性有递减与软上限。
- 成长收益来自"组合"而不是"堆数值"：满级武器 + 对应满级被动 → 进化，是每局的核心兴奋点。
- 局外成长有总上限（灯塔等级满级约 20~30 小时），避免局外数值无限膨胀稀释局内决策。

### 支柱二：失败不惩罚

- 失败也能按波次进度结算星尘，且设有保底比例，**每一局都不亏**。
- 首夜保护、挣扎模式、可随时"提前收工"结算（P0/P1 必做；更多保险见 [§8.4](#84-挫败感控制清单)）。
- 升级三选一带重铸与保底，杜绝"运气差被卡死"。

### 支柱三：压力阶梯

- 敌人强度按波次基础曲线爬升；**阶梯跳变**由每 5 夜的节奏节点承担。
- **侵蚀等级**为封测调优功能，MVP 不实现（见 [§8.5](#85-延后系统)）。
- 目标节奏：12~15 夜是"成型爽快期"，16 夜起压力逐夜上台阶，20 夜要求完整 Build + 合格操作才能通关。
- 难度是"阶梯 + 尖峰"，不是线性加血。

### 支柱四：每局都有新事

- 每夜都是 45 秒的完整小目标；每 5 夜有节奏节点（精英夜或天灾夜）。
- 抉择之昼提供随机事件卡，每局至少触发 2~3 次。
- 敌人行为差异化（冲撞、远程、自爆、潜地、召唤），配合精英词缀组合。
- 随机种子 + 每日挑战（抢先体验）+ 成就档案，保证重玩理由。

## 3. MVP 与内容分期

### 3.1 MVP 范围（约 3 个月）

| 项 | 内容 |
|---|---|
| 角色 | 3 个：守望者、铁匠、星象师 |
| 武器 / 进化 | 各 **8**（共设计 10 条进化，MVP 先做 #1~#8） |
| 被动 | **进化钥被动 8**（与 #1~#8 一一对应）+ **通用被动 ≥4**（构筑用，不绑定进化） |
| 精炼 | **8 条**（对应进化 #1~#8 的 I/II）；精炼 III 与 #9/#10 延后 |
| 敌人 / Boss / 事件 | 9 种敌人、3 个 Boss（第 10/15/20 夜）、7 张事件卡 |
| 流程与难度 | 完整 20 夜；难度 2 档（守夜人 / 灯塔） |
| 局外 | 灯塔升级树 3 项 × 5 级 |
| 保底 | P0 + P1（见 §8.4） |
| **不做** | 侵蚀等级、诅咒契约、献祭复活、无尽模式、每日挑战 |

### 3.2 抢先体验（MVP + 约 3 个月）

- 10 角色、20 武器、30 敌人、3~6 个 Boss、40 事件。
- 无尽模式、每日挑战、随机种子分享、成就系统。
- 完整灯塔升级树（4×10）；开放风暴 / 天灾难度。
- 封测验证后的侵蚀等级（可先只开硬化）。
- 补齐进化 #9/#10、精炼 III；再增 ≥1 条夜风系进化，使全量四系均 ≥15%（礁石已有 #7+#9）。

### 3.3 正式版方向

- 新区域（第二章：永冻湾）与 20+ 新敌人。
- 可选双人本地合作（难度 ×1.8）。
- 武器幻化与灯塔外观自定义（纯装饰，不卖数值）。

### 3.4 开发路线图

| 阶段 | 周期 | 目标 | 验收标准 |
|---|---|---|---|
| 原型验证 | 团队 **3 周** / 单人 **4 周**（W1–W4） | 昼夜循环 + 自动战斗 + 100 敌同屏 + 三选一 + 商店雏形 | 60fps、可玩到第 8~10 夜 |
| MVP | 团队约 3 个月 / 单人 **20 周** | 完整 20 夜 + 3 角色 + 8 武器 + P0/P1；无侵蚀/无契约 | 首局完成率 ≥ 60% |
| 封测调优 | 1 个月 | 数值曲线；可选侵蚀（先硬化）；通关率校准 | 通关率落在 §8.1 目标区间 |
| 抢先体验 | 第 5 个月 | 10 角色 / 20 武器 / 无尽模式 | 局均约 20 分钟（P95 ≤ 25），D1 完成率 ≥ 50% |
| 正式版 | 第 9 个月 | 每日挑战 + 合作 + 第二区域 | 稳定版本，社区内容可延续 |

## 4. 核心循环与一局结构

### 4.1 三圈循环

```
局外圈（长期）：  星尘 → 灯塔升级 → 解锁角色/武器/事件 → 挑战更高难度 → 星尘
局内圈（中期）：  熬过夜晚 → 获得经验珠/潮币 → 抉择之昼购买/进化 → 更完整的 Build → 下一夜
战斗圈（短期）：  走位/拾取 → 击杀 → 掉落/升级 → 变强 → 敌人压力上升 → 走位
```

### 4.2 术语（全文统一）

| 术语 | 定义 | 出现夜 |
|---|---|---|
| 精英夜 | 精英怪密集 + 进化道具掉落保障 | 第 5 夜 |
| 天灾夜 | Boss + 全局规则强化（词缀/夹击等） | 第 10、15、20 夜 |
| 节奏节点 | 每 5 夜一次的形态变化（含精英夜与天灾夜） | 第 5/10/15/20 夜 |

### 4.3 一局时间结构（标准模式）

| 夜 / 阶段 | 类型 | 时长 | 要点 |
|---:|---|---|---|
| 启程 | — | ≈30s | 选角色、难度、地图种子 |
| 1–4 | 常规 | 各 **45s** | 教学；走位与拾取 |
| 5 | **精英夜** | **60s** | 进化道具；命名精英「巨钳王」（非 Boss） |
| 6–9 | 常规 | 各 **45s** | Build 初步成型 |
| 10 | **天灾夜** | **90s** | Boss 深渊水母后；全场 +1 词缀 |
| 11–14 | 常规 | 各 **45s** | 成型爽快期 |
| 15 | **天灾夜** | **90s** | Boss 潮汐执政官；强制「潮汐夹击」形态（封测可叠侵蚀） |
| 16–19 | 常规 | 各 **45s** | 压力台阶期；**精炼 III 开放（第 18 夜，MVP 不做）** |
| 20 | **天灾夜 / 终局** | **120s** | Boss 吞噬之星（通关） |

> **精炼开放节奏**（详见 §6.6）：精炼 I（第 10 夜）→ II（第 15 夜）→ III（第 18 夜）。MVP 仅实现精炼 I/II，III 延后至封测前开放。

每两个夜晚之间有「抉择之昼」：**无强制倒计时**，可购买、升级、重铸、触发事件，也可立即跳过。UI 软提示「建议用时 **20 秒**」；超过约 40 秒可轻提示「可随时跳过」。

**局长估算**（与上表同源）：

- 纯战斗：16×45s + 60s + 90s + 90s + 120s = **1080s = 18 分钟**
- 启程 ≈ 0.5 分钟；升级三选一暂停熟练局约 1 分钟量级
- 抉择之昼：19 段，快速跳过约 5s / 正常约 10~15s → 约 **1.5~5 分钟**
- **目标：约 20 分钟**；**硬上限：25 分钟**（长期超 25 优先压缩 UI / 默认选项，而非再砍战斗）

## 5. 局内玩法

### 5.1 昼夜结构

**夜晚（战斗）**

- 自动攻击：武器自动索敌开火；玩家负责移动、拾取、躲避。
- 潮汐刷怪（有经验预算）：默认按 **夜长均匀释放**（`budget_pace=even`），避免前半夜打光预算后只剩无经验补刷；夜末保留约 **5 秒**捡珠空窗（`budget_slack_sec`）；预算数量另乘约 **1.15** 成长冗余（`budget_exp_redundancy`）。同屏压力仍由 `min_active` / floor 补刷维持（补刷无掉落）。旧版「前 12 秒稀疏 → 中段密集 → 末段加压」可通过配置回退。
- 掉落：经验珠（自动吸附）、潮币（靠近拾取）、进化道具、宝箱。经验珠与潮币**连续不在显示区内超过约 5 秒**则回收（不入账，`pickups.json` → `offscreen_despawn_sec`）；仍在屏内可一直等待拾取。
- 夜晚结束：无论敌人是否清完，进入白天；**未拾经验珠 / 潮币均不全局入账**，清场直接丢弃；按守夜进度结算。

**白天（抉择）**

- 商店：潮币购买武器/被动（每夜刷新 4 件 + 1 件折扣）。
- 重铸：卸下武器/被动回收 80% 潮币。
- 事件：随机 1 张事件卡（可跳过）。
- 休息：灯塔小幅回血（每 5 夜免费大回血）。

### 5.2 地图与移动

- 地图：单场景，灯塔居中；**氛围边界半径约 600 单位**（礁石、沉船、浅滩随机），常规战斗不要求跑满全图。
- **有效作战半径约 180~220 单位**（以灯塔为心）：45 秒常规夜内可多次往返；宝箱与主要刷怪落在此环带。
- 移动：WASD / 左摇杆，基础移速 4.2 单位/秒，+60% 移速软上限。
- 拾取：**夜明珠**（夜风系通用被动）扩大拾取半径；宝箱需主动触碰。经验珠为局内经验掉落，二者不同。屏外超时与夜末清场规则见 §5.1 / §6.7。
- **宝箱刷新**：灯塔光晕外环（约 **5~10 秒**路程，落在有效作战半径内），禁止刷到氛围边界死角。
- 潮汐退潮：每 5 夜光晕短暂外扩，露出 2~3 个藏宝点（仍在外环内）；可能引出潜地怪。

### 5.3 敌人

| 敌人 | 行为 | 危险度 | 出现夜 |
|---|---|---|---|
| 小水鬼 | 直线冲撞，基础数量单位 | ★ | 1 |
| 铁壳蟹 | 慢速近战，高血量，破甲 | ★★ | 2 |
| 水母浮游 | 远程弹幕，移动缓慢 | ★★ | 3 |
| 深潜者 | 潜地 3 秒后从玩家脚下突袭 | ★★★ | 4 |
| 爆炸贝 | 自爆，范围伤害，血量低 | ★★ | 5 |
| 鸦群 | 飞行，无视地形，速度快 | ★★★ | 7 |
| 潮汐召唤师 | 不主动近战，召唤小水鬼 | ★★★★ | 8 |
| 渊潮长枪兵 | 冲锋型，冲锋时免伤 50% | ★★★★ | 11 |
| 暗礁巨人 | 体型大，受伤分摊给周围小怪 | ★★★★★ | 14 |

**密度预算**：同屏上限 350~450（PC）；前 5 夜峰值 60，第 10 夜 200，第 15 夜 320，第 20 夜 450 + Boss。

### 5.4 精英与词缀

精英 = 基础敌人 × 词缀（2~3 个），提供 3 倍潮币；进化道具见下（有可进化项时才掉）。

**进化道具掉落上限**：

| 来源 | 规则 |
|---|---|
| 精英（含命名精英） | 本夜精英池合计最多掉 **1** 个；优先由首只击杀的精英掉落 |
| Boss | 必掉 1 个（第 15/20 夜额外见 §6.5）；**不计入**当夜精英上限 |
| 宝箱 / 事件 | 可额外掉，但受同夜「玩家持有未使用进化道具 ≤2」软上限约束 |

| 词缀 | 效果 | 反制思路 |
|---|---|---|
| 分裂 | 死亡时分裂为 2 个小号自身 | 范围伤害/穿透 |
| 传送 | 每 8 秒随机传送一次 | 控制/持续伤害 |
| 荆棘 | 近战攻击者受伤 | 远程武器 |
| 迅捷光环 | 周围敌人 +25% 移速 | 优先击杀 |
| 再生 | 脱战 5 秒回复 30% 血 | 不脱战 |
| 锁链 | 被攻击时短时减速玩家（移速×50%，持续 0.3 秒；非完全定身） | 保持距离 |

### 5.5 Boss

仅出现在天灾夜。

| 夜 | Boss | 考察点 | 附加规则 |
|---|---|---|---|
| 10 | 深渊水母后 | 弹幕环 + 分裂小水母，考验转火 | 全场敌人 +1 词缀 |
| 15 | 潮汐执政官 | 传送 + 全屏潮汐波（躲进灯塔光晕） | 强制「潮汐夹击」（两侧夹击）；封测可叠侵蚀 |
| 20 | 吞噬之星 | 多阶段（护盾 → 狂暴 → 分身） | 终局高压 |

> 第 5 夜**不是** Boss 夜。巨钳王仅为精英夜命名精英（可选皮肤/称号）。天灾附加规则亦见 [§8.3](#83-天灾夜规则)。
>
> **「潮汐反转」命名约定**：抉择之昼事件卡仍用原名「潮汐反转」（两侧夹击 + 宝箱翻倍）。第 15 夜天灾规则称「潮汐夹击」，效果仅两侧夹击、**不含**宝箱翻倍；该夜事件池**排除**「潮汐反转」，避免叠乘。

### 5.6 事件（抉择之昼）

| 事件 | 效果 | 风险/收益 |
|---|---|---|
| 暴风雨 | 全场敌人 +30% 移速；本夜掉落 +50% | 高风险高回报 |
| 潮汐反转 | 敌人从两侧夹击；宝箱翻倍（**仅事件版**；第 15 夜池排除，见 §5.5） | 改变战场形态 |
| 月食 | 视野缩小 30%；经验获取 +100% | 压迫感 + 加速成长 |

## 6. 成长机制

### 6.1 总体原则

1. **槽位即边界**：武器 4 槽、被动 6 槽。
2. **组合大于堆叠**：武器 × 被动 × 角色特性 × 进化（+ 精炼）。
3. **经验曲线封顶（非人物硬顶）**：`n ≥ 30` 时 `E(n)=E(30)`，人物等级可继续上升；每级仍触发一次三选一。
4. **乘区分离**：同乘区加算、跨乘区乘算，各乘区有软上限。

### 6.2 经验与升级

**公式**（与 [§9.2](#92-经验曲线) 表同源）：

```
E(n) = floor(22 × 1.11^(n-1) + 3×(n-1))    # 1 ≤ n ≤ 30
n ≥ 30 时 E(n) = E(30)                      # 曲线封顶；人物无等级硬顶
```

校验：第 1 级 22，第 10 级 83，第 20 级 216。目标：第 10 夜约 15 级，第 20 夜约 26~30 级。

- 每级 1 次三选一：优先已持有武器升级/进化，其次被动与稀有武器。
- 权重保底：连续 2 次无武器 → 第 3 次必出武器；连续 3 次无某被动系 → 第 4 次该系权重 ×3。
- **进化助推**：持有 ≥6 级武器且缺对应**进化钥被动**时，下一昼商店与三选一中该被动权重 ×3。
- 每级免费重铸 1 次（重掷三选一），之后每次 10 潮币，每局不限次数。
- **溢出奖励**（武器槽满且均满级、被动槽满且均满级时）：三选一改为 `config/upgrade.json` → `overflow_offers`（默认潮币补给 / 急救血包），不再自动跳过；重铸仍可用，溢出池内容固定。

### 6.3 武器系统

- **槽位**：4（可替换，回收 80% 投入）。
- **稀有度**：白 → 蓝 → 紫 → 金（传说，进化后）。与商店用语映射：

| 稀有度 | 商店/掉落文案 |
|---|---|
| 白 | 普通 |
| 蓝 | 精良 |
| 紫 | 史诗 |
| 金 | 传说 |

- **等级**：1~7；如第 5 级 +1 弹道，第 7 级解锁特性。

| 类型 | 示例（基础武器） | 特点 |
|---|---|---|
| 定向弹幕 | 鱼叉枪、水母炮 | 高 DPS，需朝向管理 |
| 环绕型 | 锚链 | 清近身，范围有限 |
| 召唤型 | 水母孢子、信天翁 | 持续输出，吃被动联动 |
| 范围型 | 灯塔圣火、雷暴云 | 清场强，单体弱 |
| 控制型 | 潮汐之缚 | 伤害低，制造安全区 |
| 爆发型 | 锚锤、巨锚投掷 | 长 CD / 近战爆发，吃减 CD |

> 「水母巢」是水母孢子的**进化名**，不是基础武器。MVP 外角色开局武器（短柄鱼叉、自动弩、月刃、沉礁巨杵、幽灵火等）在对应角色实装时补完整数值与克制。

红线：新武器必须给出「克制」与「被克制」敌人各至少一种。

### 6.4 被动与槽位

- 6 个被动槽，每件 1~5 级。
- 四系：**潮汐**（攻速/暴击/穿透）、**灯塔**（伤害/范围/燃烧）、**礁石**（防御/回复/减伤）、**夜风**（移速/拾取/经验）。
- **两类被动**（命名勿与局外灯塔树混淆）：
  - **进化钥被动**（MVP 8）：与进化路径一一对应，满级（5）才能进化；见附录 A.1。
  - **通用被动**（MVP ≥4）：不绑定进化，用于补系与构筑（如夜明珠=拾取、护身符类防御等）；**完整表须在单人计划 W12 前补齐**，原型阶段可用占位。
- 鼓励「1 武器 + 2~3 被动」配系（通常 1 钥 + 1~2 通用）。

### 7.2 解锁系统

- 角色：见 [§6.8](#68-角色)。
- 武器/被动：成就解锁后进入卡池。
- 事件：通关/失败特殊条件解锁。
- 难度：通关标准 → 风暴 → 天灾。
- 每日挑战：固定种子 + 指定角色 + 排行榜（抢先体验）。

### 7.3 星尘结算

```
星尘 = floor(基础星尘 × 进度系数 × 难度系数 × 首胜系数)
进度系数 = 波次进度(0~1) × 0.7 + 0.3    # 保底 30%
难度系数 = 守夜人1.0 / 灯塔1.25 / 风暴1.5 / 天灾2.0
首胜系数 = 该难度档位「首次通关」结算时为 1.5，否则为 1.0
           # 失败局恒为 1.0；仅通关结算可触发；每难度档位各计一次
```

失败至少拿到 30% 进度星尘，禁止零收益死亡。基础星尘 MVP 取值：**80**（灯塔难度通关期望约 `80×1.0×1.25×首胜?`，按进度再乘）。

### 8.1 难度档位

| 档位 | 敌人基础倍率 | 侵蚀开启夜（封测） | 目标通关率 |
|---|---|---|---|
| 守夜人（教学） | 0.7 | 永不 | —（练习） |

### 8.2 敌人数值公式（MVP 主难度手段）

```
敌人生命 = 基础生命 × 区域系数 × (1 + 0.10 × 夜数) × (1 + 0.15 × ⌊夜数/5⌋)
敌人伤害 = 基础伤害 × (1 + 0.04 × 夜数)
敌人数量 = 基础数量 × (1 + 0.06 × 夜数) × (1 + 0.20 × ⌊夜数/5⌋)
```

**区域系数**：MVP（第一章「灯塔海域」）恒为 **1.0**。正式版第二章「永冻湾」预留 **1.15**（届时再定）。与地图内礁石/浅滩分块无关。

`⌊夜数/5⌋` 制造阶梯感。MVP **仅靠本公式 + 天灾夜尖峰**调难度。

### 8.3 天灾夜规则

与 [§5.5 Boss 表](#55-boss) 配套：

- 第 10 夜：Boss + 全场 +1 词缀。
- 第 15 夜：Boss + **潮汐夹击**（两侧夹击；事件池排除「潮汐反转」）；封测可叠加侵蚀。
- 第 20 夜：最终 Boss 多阶段 + 高压。

### 8.4 挫败感控制清单

#### P0 — MVP 必须

1. **失败保底结算**：≥30% 进度星尘（§7.3）。
2. **首夜保护**：前 **4** 夜（与教学宽容夜对齐）死亡自动复活 1 次，并提示死因。
3. **挣扎模式（最后的灯火）**：血量归零进入 3 秒免死，击杀 5 敌即复活（每夜 1 次）；复活后 5 秒无敌。MVP 实现以 `config/frustration.json` 为准（当前每局 `max_revives=1`、`revive_invuln_sec=2.0`）。
4. **升级保底**：§6.2 权重规则。
5. **免费重铸**：每级 1 次免费重掷。
6. **死亡原因可视化**：结算页说明死因与建议。

## 9. 数值框架

### 9.1 伤害公式

```
最终伤害 = 基础伤害 × 角色系数 × 武器等级系数 × Σ(同乘区加成)
          × Π(跨乘区加成) × 暴击(×1.8) × 减伤效果
```

计算顺序：基础 → 角色 → 武器等级 → 同乘区加算和 → 各跨乘区依次乘 → 暴击 → 目标减伤。同乘区指同一属性条（如所有「攻速」来源加算后再进入跨乘区）。

示例（守望者 +5%，鱼叉枪基础 12，7 级系数 2.4，灯塔系伤害乘区 +60%，潮汐系独立乘区 +40%，暴击率 25%）：

```
12 × 2.4 × 1.05 × (1+0.6) × (1+0.4) × 1.2 ≈ 81.3/发
```

（期望暴击系数 = 0.75×1 + 0.25×1.8 = 1.2）

## 10. 技术设计

### 10.1 架构建议

- **节点系统 + 对象池**（不引入第三方 ECS）：同屏敌人数百级；预分配池，战斗中禁止运行时 `instantiate`。
- **Buff 用命令/可序列化修改器**：便于存档、回放、数值测试。
- **数据驱动**：武器/敌人/事件/Boss 配置表与代码分离；运行时只读 `config/`。
- **确定性随机**：Godot `RandomNumberGenerator` 单例（整数采样优先），支持每日挑战与回放。

### 10.2 性能预算

| 项 | 目标 |
|---|---|
| 同屏敌人 | 350~450（PC 60fps）、150（移动端 30fps） |
| 敌人 AI | **远程每 1 帧** / **近战每 2 帧** / **小怪每 4 帧**（与技术选型一致） |
| 碰撞 | 玩家↔敌人精确；敌人↔敌人只分离；投射物自定义空间哈希（不用 Physics2D） |
| 渲染 | 敌人 `MultiMeshInstance2D` 合批；粒子预算 ≤200 |
| 内存 | 对象池常驻，战斗中避免分配 |

### 10.3 存档与平台

- 存档：JSON（Steam 云同步）——解锁、灯塔等级、星尘、设置。
- 每日挑战：服务器下发种子 + 排行榜（移动端可本地排名）。
- 本地化：i18n 表，首版中英双语。

## 12. 设计红线

1. 局内槽位上限（4 武器 / 6 被动）**不得取消**，仅可通过角色特性微调。
2. 任何新武器必须给出克制与被克制敌人各至少一种。
3. 任何新保底机制（尤其 P2）上线前，必须通过 §11.1 验证。
4. 局外成长必须有总上限，禁止无限变强破坏局内平衡。
5. 每 5 夜必须有节奏节点（精英夜或天灾夜）。
6. 死亡结算永远有保底收益，禁止零收益死亡。
7. **经验表必须由公式脚本生成**，禁止手改单行。
8. **MVP 不得实现侵蚀等级与诅咒契约**。
9. **进化路径不得少于 8 条**（共设计 10，MVP 实现 8），武器类型全覆盖。
10. **被动系分布**：正式版四系均 ≥15%；MVP/过渡期允许夜风或礁石低至 10%，抢先体验前补齐。
11. **精炼与进化对齐**：共设计 10 条；MVP 至少 8 条 I/II，且与对应进化深度绑定，禁止跨类型。
12. **淬炼精华**一局最多精炼 1 把 III 或 2 把 II，禁止事件/宝箱突破此上限。
