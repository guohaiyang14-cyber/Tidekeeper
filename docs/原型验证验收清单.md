# 原型验证验收清单

> **版本**：v1.2（对齐主文档 v0.3.4 / 单人 20 周计划）  
> **日期**：2026-08-05  
> **周期**：**单人 4 周（W1–W4）**；团队归档口径为 3 周（见主文档 §3.4）  
> **范围边界**：本清单**只验收原型**——昼夜循环、移动拾取、自动战斗雏形、≤100 敌同屏、三选一雏形、商店雏形；可玩到第 **8~10** 夜。  
> **不在本清单**：完整 8 进化 / 精炼 / 7 事件 / 3 Boss 全套 / 挫败感 P0 全开 / 核心指标统计 → 见 `单人开发任务拆分表_20周.md` 与后续「MVP 验收」。  
> **验收标准**：60fps 稳定（100 敌）、可玩到第 8~10 夜、无阻断性 Bug

## 六、验收流程

### 6.1 每周末

1. 开发自测 → 交叉测试 → 策划抽检  
2. **P0** 必须 100% 通过，否则不进入下一原型周  
3. **P1** 允许 ≤2 项带入下一周

### 6.2 阻断性 Bug

- 无法启动或崩溃  
- 昼夜循环断裂  
- 同屏 100 敌帧率持续 <30fps  
- 卡死无法恢复
