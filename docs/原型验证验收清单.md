# 原型验证验收清单

> **版本**：v2.0（对齐主文档 v0.3.4 / 单人 20 周计划）
> **日期**：2026-08-17
> **周期**：单人 20 周（W1–W20）；本版将验收范围从原型（W1–W4）扩展到**战斗核心（W5–W9）+ 成长（W10）**
> **范围边界**：本清单验收已落地的 W1–W10 内容——昼夜循环 / 移动拾取 / 自动战斗 / 8 武器 / 9 敌人 / 6 词缀 / 3 Boss 多阶段 / 进化系统；并已机检打通「第 20 夜击杀吞噬之星 → 通关」路径。
> **不在本清单**：精炼 I/II（W11）、被动全量（W12）、商店完善 / 7 事件 / 3 角色 / 灯塔树 / 星尘 / 存档（W13–W16）、挫败感 / 难度 / UI 完善 / 性能 350 敌 / i18n / 首局完成率（W17–W20）→ 见 `单人开发任务拆分表_20周.md` 与后续「MVP 验收」。
> **验收标准**：100 敌同屏稳定 60fps；可玩到第 8~10 夜（已达，且已打通 20 夜通关）；无阻断性 Bug。
> **机检说明**：标注「通过（机检）」的项由 `godot_project/scenes/tests/` 下专项测试覆盖（`w1_unit` / `w2w3_enemy` / `w5_weapon` / `w8_enemy_affix` / `w9_boss` / `w10_evolution` 等；全回归 17 场景 exit 0）。标注「待验收」需人工 / Perf 试玩。
> **已知限制**：`w8`/`w9`/`w10` 专项测试含 100 敌刷怪与 Boss 战模拟，单次运行较长（数十秒级），CI 建议设超时；性能（帧率 / 崩溃 / 内存）只能人工或 Profiler 实测，机检仅验证「不崩溃 + 逻辑正确」。

## 七、验收流程

### 7.1 每周末

1. 开发自测 → 交叉测试 → 策划抽检
2. **P0** 必须 100% 通过，否则不进入下一原型周
3. **P1** 允许 ≤2 项带入下一周

### 7.2 阻断性 Bug

- 无法启动或崩溃
- 昼夜循环断裂
- 同屏 100 敌帧率持续 <30fps
- 卡死无法恢复
