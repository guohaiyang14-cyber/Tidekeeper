# 原型验证验收清单

> **版本**：v2.6（对齐主文档 v0.3.4 / 单人 20 周计划）
> **日期**：2026-08-18
> **周期**：单人 20 周（W1–W20）；本版将验收范围从原型（W1–W4）扩展到**战斗核心（W5–W9）+ 成长（W10–W12）+ 商店完善/经济闭环（W13）+ 事件卡/潮汐夹击（W14）**
> **范围边界**：本清单验收已落地的 W1–W14 内容——昼夜循环 / 移动拾取 / 自动战斗 / 8 武器 / 9 敌人 / 6 词缀 / 3 Boss 多阶段 / 进化系统 / 精炼系统（I/II）/ 被动系统（12 被动 + 8 通用效果桶）/ 商店完善（重铸回收 80% + 休息灯塔回血）/ 事件系统（7 事件卡数据驱动 + 第 15 夜潮汐夹击天灾 + 潮汐反转事件强制两侧夹击）；并已机检打通「第 20 夜击杀吞噬之星 → 通关」路径。
> **不在本清单**：3 角色 / 灯塔树 / 星尘 / 存档（W15–W16）、挫败感 / 难度 / UI 完善 / 性能 350 敌 / i18n / 首局完成率（W17–W20）→ 见 `单人开发任务拆分表_20周.md` 与后续「MVP 验收」。
> **验收标准**：100 敌同屏稳定 60fps；可玩到第 8~10 夜（已达，且已打通 20 夜通关）；无阻断性 Bug。
> **机检说明**：标注「通过（机检）」的项由 `godot_project/scenes/tests/` 下专项测试覆盖（`w1_unit` / `w2w3_enemy` / `w5_weapon` / `w8_enemy_affix` / `w9_boss` / `w10_evolution` / `w11_refine` / `w12_passive` / `w13_shop` / `w14_event` / `upgrade_logic` 等；共 21 场景）。**全部 21 场景全 exit 0**（2026-08-18 专项修复 3 个历史遗留失败：`upgrade_logic` / `w2w3_enemy` / `w8_enemy_affix` 均为测试侧问题——开局默认武器致首次三选一走升级分支不增槽、商店随机 6 件子集不保底武器、`start_night` 首帧杂兵被计入精英分裂；逻辑本身正确，修复后三场景复跑全绿）。标注「待验收」需人工 / Perf 试玩。
> **已知限制**：`w8`/`w9`/`w10` 专项测试含 100 敌刷怪与 Boss 战模拟，单次运行较长（数十秒级），CI 建议设超时；性能（帧率 / 崩溃 / 内存）只能人工或 Profiler 实测，机检仅验证「不崩溃 + 逻辑正确」。月食「视野」与潮汐反转「宝箱翻倍」仅有 getter（对应系统未落地），见 4.5.4 / 4.5.5。
