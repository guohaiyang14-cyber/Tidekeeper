# 单人开发任务拆分表（20 周）

> **版本**：v1.0（单人 + agent，对齐主文档 v0.3.4）
> **日期**：2026-08-05
> **周期**：20 周（约 5 个月）
> **开发模式**：单人 + AI agent
> **总人天**：100 人天（20 周 × 5 天）+ agent 加速
> **范围**：保持 MVP 全量（3 角色 / 8 武器 / 8 进化 / 8 精炼 I-II / 9 敌人 / 3 Boss / 7 事件）
> **前序文档**：[MVP 开发任务拆分表.md](MVP开发任务拆分表.md)（团队 v1.1，已归档参考）

---

## 一、与团队版（v1.1）的差异

| 维度 | 团队版 v1.1 | 单人版 v1.0 |
|------|------------|------------|
| 周期 | 12 周 | 20 周 |
| 人天 | 380（理想）/ 120（可用，2.1× 超载） | 100（可用）+ agent 加速 |
| 程序 | 2 人 | 1 人 + agent |
| 沟通成本 | 高（需协调） | 零（单人无协调） |
| agent 依赖 | 低 | 高（编码主力） |
| 范围 | MVP 全量 | MVP 全量（不变） |

**可行性依据**：
- 单人 100 人天 + agent 编码加速 2-3× ≈ 200-300 有效编码人天
- 团队版程序部分约 250 人天（扣除 UI/策划/缓冲）
- 单人无沟通开销（省约 15%）、无上下文切换（省约 10%）
- 砍 P2 任务（粒子优化/埋点/双语）省约 30 人天
- **结论**：单人 100 人天 + agent 加速 ≈ 团队 250 人天程序产出，可行
