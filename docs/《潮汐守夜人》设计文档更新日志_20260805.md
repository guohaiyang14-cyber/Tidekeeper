### 2.2 精炼系统（§5.6）— 全新章节

**定位**：武器进化后的**终极养成层**，第 10 夜起开放

#### 系统核心

| 项目 | 规则 |
|------|------|
| 资源 | 「淬炼精华」，专属货币，一局约 5~7 个 |
| 消耗 | 精炼 I ×1、II ×2、III ×3 |
| 获取 | 第 10 夜 Boss ×1、第 15 夜 Boss ×2、第 20 夜 Boss ×3、第 12 夜起精英 30% 概率 ×1 |
| 解锁节奏 | I（10 夜）→ II（15 夜）→ III（18 夜） |

#### 10 条精炼路径（设计全集）

| # | 进化武器 | 精炼路线 | 核心强化方向 |
|---|---------|---------|------------|
| 1 | 深渊鱼叉 | 深溯之径 | 精准追踪 → 弹射强化 → 暴击穿透全敌人 |
| 2 | 永昼圣火 | 耀阳之径 | 灼烧范围 → 灼烧伤害 → 死亡引爆 |
| 3 | 风暴之锚 | 雷霆之径 | 闪电链数 → 闪电伤害+减速 → 终点雷击 |
| 4 | 水母巢 | 群生之径 | 爆炸范围 → 召唤物数 → 爆炸增殖 |

> **现行口径（v0.3.3+）**：#4 III 正式名为「爆炸生召唤」（附录 B.4「生生不息」），上表「爆炸增殖」为 v0.2 历史命名，勿再用于实现。
| 5 | 湮灭雷暴 | 苍穹之径 | 连锁次数 → 落雷伤害 → 雷云持续 |
| 6 | 深渊水母王 | 漩涡之径 | 弹幕+漩涡 → 定身强化 → 毒水母群 |
| 7 | 永恒锚轮 | 不屈之径 | 锚圈数 → 反弹真实伤害 → 震荡波 |
| 8 | 永恒鸥群 | 翱翔之径 | 鸥群数 → 暴击强化 → 死亡召唤 |
| 9 | 永夜潮汐 | 潮汐之径 | 减速+击退 → 眩晕+频率 → 潮湿 Debuff |
| 10 | 星海锚坠 | 陨星之径 | CD+伤害 → 眩晕+爆炸 → 锚压百分比伤害 |

**MVP 范围（v0.2.1）**：仅实装 #1~#8 的精炼 I/II；#9/#10 与全部精炼 III 延后至封测前。

#### 新增 3 条平衡性硬约束（适用于精炼层）

| 约束 | 规则 | 目的 |
|------|------|------|
| **百分比伤害上限** | 精炼 III 级 ≤ 2%/秒，持续 ≤ 3 秒 | 防止 Boss 战秒杀级伤害 |
| **控制叠加上限** | 敌人可行动时间 ≥ 30% | 防止永久控制 |
| **DPS 倍率上限** | 精炼 III 级 ≤ 3.5× 进化后 DPS | 防止精炼替代 Build 决策 |

> 说明：上述 3 条约束定义在 §5.6.4，**验收对象为精炼路径**；进化路径另有独立数值调优，不套用「精炼 III DPS 倍率」口径。

## 六、策划团队注意事项

### 需要重点关注的设计决策

1. **每轮至多 1 次定身**（#6 深渊水母王）  
   - 防止永久控制的关键约束，开发需实现「定身冷却 / 每轮计数」逻辑

2. **伤害递减机制**（#3 风暴之锚、#5 湮灭雷暴）  
   - 链跳转/连锁每跳按比例递减，DPS 计算基于此逻辑

3. **大范围 ≠ 全屏**（#10 星海锚坠 / 陨星之径）  
   - 覆盖约屏幕 70%，具体比例待开发微调

4. **淬炼精华稀缺性**  
   - 一局最多精炼 1 把 III 或 2 把 II，是核心决策压力来源

5. **局长验收：约 20 分钟，P95 ≤ 25 分钟**  
   - 勿再使用 22~28 / 28~35 旧口径；若实测长期 >25，优先压缩昼间 UI / 默认选项，再考虑微调夜长

### 建议开发时优先验证

| 优先级 | 验证项 | 原因 |
|--------|--------|------|
| P0 | #6 深渊水母王定身频率 | 每轮限 1 次需实测手感 |
| P0 | #10 锚压 **1%/秒×3s** 对 Boss | 百分比伤害实机验证（红线上限仍 ≤2%） |
| P1 | 淬炼精华全局获取量 | 一局 5~7 个估算需实玩验证 |
| P1 | 控制叠加上限 | 可行动时间 ≥30% 需实战体验 |
| P1 | 局均时长分布 | 确认均值约 20、P95 ≤ 25，而非仅看战斗段 |
